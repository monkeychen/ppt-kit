# Release Note：pptkit v0.3.1

> pptkit v0.3.1 是提升还原 PPTX 开箱即用编辑品质与专业排版质感的关键里程碑版本。
> 本版本彻底告别「一地碎玻璃」式的物理切块还原，全面引入「卡片语义流式成组、图层排他清洗、双母版自动归纳、字号与色彩阶梯规约」四大核心支柱。
> 生成的 PPTX 文本具备原生多段落流式折行能力、卡片拖拽不散架、多页体积缩减超 80%，达到专业级排版标准。

---

## 1. 版本内容摘要

pptkit v0.3.1 彻底重构了位图逆向还原管线的前后端处理逻辑。通过卡片语义成组算法将原本碎片化的几十个散装文本框收敛为原生多段落文本流，彻底消除了图标伪字符与卡片误判为箭头等视觉缺陷；同时引入跨页双母版（Slide Master）自动归纳与 OpenXML 媒体流全局共享去重技术，辅以字号阶梯规约与 CIELAB 调色板收敛，使 10 页全图 PPT 体积由原先的数十兆降至轻量级，并呈现高度一致的专业级排版视觉。

---

## 2. 变更记录

### Added
- **卡片语义流式成组（F31）**：同一信息卡片/容器内的标题、正文、列表与说明文字自动聚合为单一原生多段落文本框，各段落独立继承原文字号与行距，修改文字时自动弹性折行，拖动卡片整体跟随。
- **双母版（Slide Master）模板自动归纳（F33）**：多页文档转换时自动计算页面底图相似度，智能归纳封面母版（Title Master）与正文母版（Content Master），并将跨页共有 Header/Logo 等固定构件抽取至母版层。
- **PPTX 媒体流全局去重与瘦身机制（F33）**：生成的 PPTX 中多页共享相同母版底图时，底层仅写入单一物理媒体资源（`ppt/media/`），消除多页全幅位图冗余，多页 PPTX 体积缩减 80% 以上。
- **字号黄金阶梯量化规约（F34）**：建立 `[36, 32, 28, 24, 20, 16, 14, 12, 10, 9]` 黄金排版阶梯，自动吸附对齐因 OCR 采样误差引起的微小字号漂移（如 13.8pt、14.2pt 统一收敛为 14.0pt）。
- **CIELAB 调色板收敛（F34）**：在感知均匀的 CIELAB 色彩空间内执行主导色聚合，消除人眼不可区分的微小色差造成的文本颜色乱跳（如多个微弱偏差的深蓝色收敛为单一主品牌色）。

### Changed
- **微碎片图片过滤与受限凝聚聚类（F32）**：过滤 `< 24px` 的微小无效图层碎屑，采用带最大尺寸门限（`max_cluster_side_emu = 1580000`）的层次凝聚聚类，既合并相近小插图又杜绝横排多图标连锁失控。
- **标题与短语标点智能清洗（F30）**：自动规约卡片短标题及独立短语尾部的多余句号（`。`、`.`）与非成对标点符号残影，保持 PPT 标题的凝练排版视觉。
- **单页文本框数量断崖式收敛**：典型 12 步流程卡片幻灯片的孤立文本框由原本的 75+ 个骤降至 15~20 个语义卡片框，可编辑交互体验提升 100%。

### Fixed
- **图标内伪单字符智能抑制（F28）**：消除齿轮、时钟、书本等高对比度矢量图标内部被 OCR 误识生成的伪单字符（如 `¢`、`口`、`G`、`目`）。
- **卡片长宽比与填充率几何防误判守卫（F29）**：为形状分类器增加 `aspect_ratio >= 1.8` 与 `fill_ratio >= 0.80` 防御屏障，彻底根除高填充率大矩形卡片被误判为右箭头的缺陷。

## 3. 交付物清单与获取方式

### 3.1 独立单文件可执行文件（免 Python 环境）
- **macOS (Apple Silicon)**：`dist/pptkit-macos-arm64.tar.gz`
- **Linux (x86_64)**：`dist/pptkit-linux-x86_64.tar.gz`
- **Windows (x86_64)**：`dist/pptkit-windows-x86_64.zip`（内含 `pptkit.exe`）

运行 CLI 转换：
```bash
./pptkit convert input.jpg -o out/
```

一键启动 Web 工作台：
```bash
./pptkit gui
```

### 3.2 Python 包与 CLI
```bash
uv sync
uv run pptkit convert <input> -o out/
uv run pptkit gui
```

## 5. 已知问题与下版建议 Backlog

1. **表格与卡片混合排版层级微调**：在极少数超密集网格混排场景下，微型卡片与单元格边界距离非常接近，后续版本可进一步引入图层拓扑力导向分离。
2. **多语言排版黄金字号分流**：当前黄金字号阶梯以中文/通用幻灯片比例为基准，后续版本可针对全西文字符段落引入定制的 point scale。
