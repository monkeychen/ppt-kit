# Release Note：pptkit v0.3.0

> pptkit v0.3.0 是首个提供本地图形化工作台（Web GUI）的重大功能版本。
> 本版本新增零外部网络依赖的本地 Web GUI 转换器与交互式前后视觉对比画板，用户只需拖拽即可完成幻灯片还原，并能通过滑动分割线、低置信元素虚线框标注及像素差异热力图直观检验还原保真度。

---

## 1. 版本内容摘要

pptkit v0.3.0 带来了全新的本地 Web GUI 交互式转换工作台，运行 `pptkit gui` 即可一键唤起浏览器工作区。用户可直接拖拽各类幻灯片文件（矢量/扫描 PDF、纯图片 PPTX、图片等）并实时查看逐页图层逆向还原流式进度；转换完成后，通过专业级 Keynote/Linear 质感工作台自由拖拽左右滑动百叶窗对比线，辅以多页缩略图底栏、低置信元素标注浮层、差异热力图与画布缩放平移手势，实现完全私密、零数据外流的极速还原体验。

---

## 2. 变更记录

### Added
- **`pptkit gui` 本地工作台命令（F20）**：支持 `--port 8765`、`--host 127.0.0.1`、`--no-browser` 参数。内置秒级轻量 HTTP 服务，端口冲突时自动探测顺延可用端口，终端 `Ctrl+C` 优雅关闭。
- **拖拽式多源格式上传与预检（F21）**：支持 `.pdf`, `.pptx`, `.png`, `.jpg`, `.jpeg`, `.webp` 文件拖拽，前端实时预检文件格式与大小，并提供高级解析策略（自动探测/强制矢量/位图图层拆解）及 OCR 引擎快捷配置抽屉。
- **SSE 流式实时进度推送（F22）**：提供 `GET /api/events/{session_id}` 服务端推送接口，实时反馈页面开始、逐页耗时、SSIM 评分与图层提取状态，消除等待焦虑。
- **百叶窗滑动 Before/After 视觉比对器（F23）**：实现原图与生成 PPTX 无头渲染图的双图居中对比画板，用户可自由拖拽中线实时观察文字对齐、边框间距与图层分离效果。
- **多页缩略图底栏导航（F24/M3）**：多页文档转换完成后展示底部水平缩略图卡片轨道，附带单页 SSIM 评分彩色胶囊（≥0.90 绿、0.80-0.89 橙、<0.80 红），支持点击即时无闪烁切页。
- **低置信度元素标注图层与浮层提示（F24/M3）**：提供 `/api/report/{id}/elements/{page}` 接口，一键切换「标注低置信元素」后，在 PPTX 渲染图上叠加带动画的高亮虚线框（置信度 `< 0.60` 或降级位图），鼠标悬浮展示原文本与属性卡片。
- **像素差异热力图一键切换（F24/M3）**：支持在「滑动对比」「仅看可编辑 PPTX」「仅看原图」「差异热力图」之间一键切换，直观呈现红蓝像素误差分布。
- **画板手势缩放平移与全局快捷键（F24/M3）**：支持鼠标滚轮在 50% ~ 400% 范围内以鼠标为中心平滑缩放，支持拖拽平移与双击重置；支持全局快捷键：`1` 滑动对比、`2` 仅 PPTX、`3` 仅原图、`4` 热力图、`[`/`]` 翻页、`0` 重置。
- **质量度量面板与一键导出（F26, F24）**：度量卡片呈现 SSIM 保真度、可编辑文本段数、原生形状数与本地重构耗时；提供「下载原生可编辑 PPTX」与「下载质量报告」按钮。

### Changed
- **零外部运行时依赖**：全部 Web GUI 静态资源（HTML/CSS/JS/SVG）单文件内嵌，零 CDN 网络请求，断网环境下功能 100% 完整可用；同时保持零新增第三方 Python 轮子依赖，严格维护 PyInstaller 跨平台单文件二进制分发体积与稳定性。
- **暗色/浅色工作台主题**：默认专业 Keynote Studio 暖灰浅色质感，支持深浅色无缝切换，界面全中文化并符合现代桌面工作站体验。

### Fixed
- **PyInstaller 独立构建静态资源加载**：适配单文件打包解压临时目录（`sys._MEIPASS`），确保在预编译独立二进制中执行 `pptkit gui` 静态资产均可正常加载。
- **TableElement 单元格遍历类型健全性**：修正页级元素拓扑生成器中对于表格二维单元格数组的访问逻辑，消除了潜在的类型不匹配隐患。

## 3. 交付物清单与获取方式

### 3.1 独立单文件可执行文件（免 Python 环境）
- **macOS (Apple Silicon)**：`pptkit-macos-arm64.tar.gz`
- **Linux (x86_64)**：`pptkit-linux-x86_64.tar.gz`
- **Windows (x86_64)**：`pptkit-windows-x86_64.zip`（内含 `pptkit.exe`）

直接启动 GUI 工作台：
```bash
./pptkit gui
```

### 3.2 Python 包与 CLI
```bash
uv pip install -e .
uv run pptkit gui
```

## 5. 已知问题与下版建议 Backlog

1. **拖拽多文件批量排队**：当前版本单次会话处理单个选定文件（支持包含数十页的多页文档），后续版本可支持一次性拖入多个文件并以队列形式批量转换。
